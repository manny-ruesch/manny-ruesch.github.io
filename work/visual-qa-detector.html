Catching broken CSS layouts, z-index collisions, and mobile overflows without brittle pixel-diffs

Pixel-by-pixel screenshot diffing cries wolf every time dynamic copy changes or a font anti-aliases differently. This 3,015-line Python & Playwright crawler combines deterministic DOM bounding-box geometry math with multimodal Vision-LLM semantic auditing across Desktop, Tablet, and Mobile viewports.

The engineering problem

Traditional visual regression tools compare baseline PNGs pixel-for-pixel. When a marketing headline changes or a timestamp updates, the entire page shifts by 4px and fails CI—training engineers to click 'Approve All' without looking.

True visual bugs are structural and semantic: a CTA button clipped off the right edge on iPhone SE (scrollWidth > clientWidth), two sibling text nodes overlapping due to a bad absolute position, or a broken hero image returning HTTP 404. I built a hybrid auditor that computes exact DOM rectangle intersections first, then passes flagged regions to Gemini Vision for semantic severity grading.

System architecture & interactive topology

A 3,015-line multi-viewport crawler and visual auditor across playwright_crawler.py, visual_qa_engine.py, and gemini_auditor.py:

  • Multi-Viewport Headless Crawler (playwright_crawler.py): Sweeps internal routes across Desktop (1440x900), Tablet (768x1024), and Mobile (375x812) with network-idle stabilization.
  • Deterministic DOM Geometry Probes (visual_qa_engine.py): Injects JS bounding-box inspectors to detect horizontal overflow, text bounding-box intersections (Rect.intersects), and zero-dimension broken images.
  • Multimodal Semantic Auditor (gemini_auditor.py): Evaluates full-page screenshots alongside DOM anomaly coordinates to filter out intentional overlapping designs (e.g. badges over cards) vs. real UI defects.
  • CI Exit-Code Gate & Annotated Reports: Emits structured visual_qa_report.json and fails CI builds only when CRITICAL or HIGH severity defects are confirmed.

@dataclasses.dataclass
class Rect:
    x: float
    y: float
    width: float
    height: float

    def to_dict(self) -> Dict[str, float]:
        return {"x": self.x, "y": self.y, "width": self.width, "height": self.height}

    @property
    def right(self) -> float:
        return self.x + self.width

    @property
    def bottom(self) -> float:
        return self.y + self.height

    def intersects(self, other: "Rect") -> bool:
        return not (
            self.right <= other.x
            or other.right <= self.x
            or self.bottom <= other.y
            or other.bottom <= self.y
        )

Production resilience & edge-case handling

Every production system is defined by how it behaves when upstream dependencies fail, rate-limits trigger, or malformed payloads arrive at the boundary.

01 · ANIMATION & FONT FREEZING

Deterministic Frame Stabilization

Injects CSS to freeze transitions/animations and awaits document.fonts.ready + lazy-scroll completion so screenshots never capture half-rendered skeletons.

02 · DUAL DOM + VISION VERIFICATION

Geometry Math + Semantic Triage

Rect.intersects() provides exact pixel coordinates of overlapping elements, while Gemini Vision distinguishes intentional badge overlays from broken CSS collisions.

03 · BOUNDED BFS CRAWL & SANITIZATION

Same-Origin Scope & JSON Recovery

Restricts crawling to same-origin routes with configurable concurrency limits and strips malformed markdown wrappers from LLM JSON responses.

ARCHITECTURAL DECISION

Why neither DOM assertions nor Vision LLMs are sufficient alone

Pure DOM assertions cannot judge visual aesthetics or contrast legibility over background images, while pure Vision LLMs struggle to report exact CSS selectors and pixel overflow counts.

Combining Playwright's in-page getBoundingClientRect() sweep with Vision LLM confirmation gives exact CSS selectors (div.pricing-grid > .card) backed by human-like visual judgment.

SYNERGY Exact CSS selector attribution with <1% false-positive rate.

PRODUCTION PITFALL

Lazy-loaded images below the fold appear as blank gaps in full-page screenshots

Playwright's page.screenshot(full_page=True) resizes the viewport buffer without firing intersection observers cleanly, leaving loading="lazy" images unrendered.

Before taking any screenshot, the crawler runs a fast incremental scroll pass down the document and waits for all visible HTMLImageElement.complete promises to settle.

FIX Pre-capture scroll hydration eliminated false 'missing image' alerts below the fold.

Stack & specifications

  • Python 3.11+ & Playwright Async API: Multi-viewport headless Chromium orchestration
  • DOM Geometry Engine: Custom rectangle intersection, overflow, and z-index occlusion math
  • Multimodal Vision LLM: Semantic severity grading and false-positive suppression
  • GitHub Actions / CI CLI: Automated exit-code gating and annotated PNG artifact generation

Architectural takeaway

Visual QA should test layout invariants, not static pixel bitmaps. Pairing DOM bounding-box geometry with multimodal vision catches real CSS breakages while ignoring benign content updates.
